
# 📻 RADIO DEWI ANJANI FM 104.6

### Aplikasi Streaming Radio Resmi

Selamat datang di repository resmi pengembangan Aplikasi Radio Dewi Anjani FM 104.6.

Aplikasi Android ini dikembangkan untuk memudahkan masyarakat mendengarkan siaran Radio Dewi Anjani secara online kapan saja dan di mana saja.

## 📡 PROFIL RADIO

- Nama: Radio Dewi Anjani FM
- Frekuensi: 104.6 FM
- Lokasi: Anjani, Lombok Timur, NTB
- Website: https://www.radiodewianjani.my.id

## 📱 INFORMASI APLIKASI

- Platform: Android
- Framework: Flutter
- Repository: radio-dewi-anjani01

## ✨ FITUR APLIKASI

- Radio streaming online.
- Pemutar audio.
- Akses siaran Radio Dewi Anjani.
- Akses website resmi radio.
